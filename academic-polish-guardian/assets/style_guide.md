# 学术文体风格指南（style guide）

润色前必须先确认目标文体（genre），不同文体的语气、人称、时态要求不同。若任务未指定，按**期刊论文（journal article）**处理并在 uncertainty 中注明。

## 1. 期刊论文（英文）

- 人称：方法/结果可用 we 或被动语态，全篇统一；不用 one / you。
- 时态：已完成的实验与结果用过去时；普遍事实与图表内容用现在时；结论主张用现在时。
- 语气：克制。删除或弱化无证据的宣传词（novel、excellent、remarkable、breakthrough、revolutionary）；删除绝对化表述（the best、perfect、completely），除非原文有数据支撑——且只能删词不能改数据。
- 摘要：不用文献引用编号（除非目标期刊允许）；时态以过去时叙述做了什么、现在时陈述结论。
- 缩写：首次出现"全称（ABBR）"，之后只用 ABBR；公认缩写（XRD、XPS、SEM、TEM、OER 视期刊而定）也建议首次定义。

## 2. 学位论文

- 人称：中文论文不出现"我"；用"本文/本研究/笔者"（按学校规范）。英文 thesis 同期刊论文但更保守。
- 语气：描述性为主，避免口号式语句；章节之间用书面连接语。

## 3. 基金申请书（中文）

- 句式：书面语、无人称；动宾结构开头（"发展……、建立……、阐明……"）。
- 连接：使用"为此、然而、此外、因此"推进论证；研究意义—现状—问题—方案—预期影响的标准逻辑。
- 强度：已证实结果用"表明/证实"，初步结果用"初步表明"，前景用"有望"；不用"革命性/颠覆性"除非有证据。

## 4. 审稿回复（response to reviewers）

- 语气：礼貌、直接、逐条对应；先感谢后回应；改动处给出稿件位置（页/行/段）。
- 不用情绪化或防御性措辞；不同意审稿意见时用证据而非语气反驳。

## 5. 通用排版约定

- 数字与单位之间留空格（317 mV）；单位符号不随单复数变化（mV 不加 s）。
- 化学式下标、温度 ℃/K、× 号（2 × 4 cm2）按期刊风格统一；全文统一 toward 或 towards、mL 或 ml。
- 图/表指向统一格式：Fig. 2 或 Figure 2 全篇一致（与目标期刊一致）。
- 中文正文用全角标点；英文正文用半角标点；中英混排时数字与英文单位用半角。
