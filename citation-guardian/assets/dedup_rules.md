# 文献去重判据（dedup rules）

去重决定必须可解释：每条合并/不合并都给出命中的判据与证据字段。判据按强度分层，命中高层即可合并；只有低层相似时必须**不合并**并说明理由。

## 合并判据（满足任一即候选合并）

1. **DOI 相同**（强度：确定）——规范化（小写、去 https://doi.org/ 前缀）后一致。
2. **规范化题名相同 + 年相同**（强度：高）——题名小写、去标点、去多余空格后一致，出版年相同。
3. **题名高度相似（≥0.9）+ 第一作者相同 + 年相同**（强度：中）——常见于不同数据库导出的字段差异（全大写期刊名、页码格式、作者缩写差异）。合并时保留字段更全的一条为主条目，差异写进合并记录。

## 特殊情形

- **预印本 ↔ 正式版**：题名与作者一致、年份相邻（预印本通常早 1–2 年）→ 合并，**以正式版为主条目**，合并记录注明"preprint → published version"；材料中没有正式版时保留预印本并在 uncertainty 注明。
- **期刊版 ↔ 会议扩展版**：题名相似但发表载体类型不同 → 默认**不合并**，除非任务明确要求；两条都在正文中被引时各自保留编号。
- **同名作者不同文献**：第一作者相同甚至年相同，但规范化题名不同 → **不合并**，理由写"同一作者的不同著作"。
- **中英文题名同一文献**：中文题名与其英文译名指向同一篇（卷期页一致）→ 合并，按目标规范选择主条目语言，另一题名写入合并记录。

## 输出要求

每个候选对必须给出：`decision`（merge / not_merge / unresolved）、`matched_criteria`（命中的判据编号）、`evidence`（两条目的对比字段：题名/作者/年/卷期页/DOI）、`survivor`（合并时保留哪条）。`unresolved` 用于材料不足以判定的情况，不许猜。
